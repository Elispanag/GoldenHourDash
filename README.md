# Golden Hour Dash

Εργασία στο μάθημα Εισαγωγή στην ανάπτυξη παιχνιδιών

About Game 
Ο παίκτης στο Golden Hour Dash αναλαμβάνει τον ρόλο ενός κύβου που κινείται ασταμάτητα προς τα εμπρός σε μια τρισδιάστατη πίστα. 
Χειρισμός : Ο κύριος χειρισμός γίνεται με τα πλήκτρα Α και D (ή τα βελάκια αριστερά/δεξιά), επιτρέποντας στον παίκτη να αλλάζει λωρίδα και να αποφεύγει τα εμπόδια. 
            Το πλήκτρο Space χρησιμοποιείται για άλμα πάνω από εμπόδια. 
Σκοπός : Ο βασικός σκοπός του παίκτη είναι να επιβιώσει για όσο το δυνατόν περισσότερο, διανύοντας τη μεγαλύτερη δυνατή απόσταση. 
        Αυτό επιτυγχάνεται αποφεύγοντας τις συγκρούσεις με τα εμπόδια και την πτώση από την πίστα, καθώς κάθε λάθος οδηγεί σε απώλεια ζωής. 
        Η συσσώρευση υψηλού σκορ (βάσει της απόστασης που διανύει) και η αύξηση της δυσκολίας με την πάροδο του χρόνου αποτελούν τους κύριους στόχους για την επίτευξη της μέγιστης πρόκλησης.
